## Flags
- The app code needs the layout `/app/{graphdispatch,seed,scripts,runs}`, so the image installs the package editable instead of into site-packages (otherwise seed paths break).
- Memory limits add up to 750 MB on a 1 GB host; the runbook adds a 2 GB swap file. Measured use is about 115 MB combined, so the limits are generous.
- `TRUST_PROXY=0` is the right setting for plain HTTP straight to the instance. `TRUST_PROXY=1` is only safe behind CloudFront or a load balancer that overwrites the headers.
- The expiry task frees units to `available` (the only status an assignable unit can have), not a stored per-unit seed status.
- `phase4a/intake_results.csv` is still modified in the working tree from the operator's rerun and is not in this commit.
- The role policy and IMDSv2 hop-limit guidance are untested without AWS; the advisor should review `deploy/RUNBOOK.md` before use.
